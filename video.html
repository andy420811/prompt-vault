設定與備份

YouTube 匯入（選填）

不填金鑰也能用：貼影片連結就會帶縮圖與標題。填了 YouTube Data API 金鑰才能「一鍵拉整個頻道」與更新觀看數。

AI 金鑰（與 Prompt 庫共用）

腳本拆分鏡、AI 想標題與說明欄都在這一頁直接跑，用的是跟 Prompt 庫同一組金鑰（存在這台裝置的瀏覽器，不會上傳）。在這裡填等於在 Prompt 庫也填好了。

只補「空著」的欄位，你自己寫過的一律不動。有腳本或大綱時效果最好；沒有金鑰就不會跑。

拆鏡規則（AI 怎麼寫每一鏡的 prompt）

「腳本→分鏡」時，AI 會依這裡啟用的規則來寫每一鏡的 prompt。可以直接勾選開關、修改內容、或新增自己的規則；關掉的不會送給 AI。改完自動存，只影響之後新拆的分鏡。

拆鏡範本（描述手法／風格）

範本是一套「描述手法＋範例示範（few-shot）」——套用哪個範本，AI 就照那套手法與筆觸寫每一鏡，解決 prompt 生硬的問題。預設是通用的「小說式沉浸描述」（把每一鏡寫成小說段落、題材不限）；也可以自己做成特定風格。這跟上面的「拆鏡規則」是分開的兩套：規則管『怎麼寫得好』，範本管『用什麼描述手法與風格』。可切換、編輯、新增，改完自動存，只影響之後新拆的分鏡。

頻道統計

Prompt

腳本 → 分鏡

AI 會把旁白拆成一個個鏡頭，並寫好可以直接餵給生成模型的英文提示詞。拆完可以寫回腳本、排成章節，或整組建進 Prompt 庫變成分鏡堆疊並掛到這支影片上。

自己決定每一鏡從哪句切到哪句：點句子之間的「＋ 在這裡切」新增一刀，點「✂」取消（點句子本身也可以切在它前面）。畫面會即時顯示切成幾鏡。切好按下面按鈕，AI 會照你的切法一鏡一鏡把每組句子展開成完整 prompt，不會自己改鏡數。

AI 想標題與說明欄

一次生成所有物件參考圖 prompt

把製作聖經裡的所有物件（企劃共用＋本集追加）組成一段提示詞，餵給生成模型就能在同一張圖裡一次畫出全部物件的設定參考圖。可自行修改後再複製。

素材生成工作站

分鏡表、prompt 都列在這裡；每一鏡可以放參考圖／參考影片連結／註解，整理好素材再去生成。內容會存在這支影片上。

AI 依大綱設計人物與場景

AI 會讀這一集的大綱與腳本劇情，設計登場人物的造型／服裝／氣質、主要場景，並定調整體視覺風格。勾選要採用的，選擇加到「企劃共用」或「只加這一集」，再套用。人物／場景描述會直接接到拆分鏡的 prompt 前面。
